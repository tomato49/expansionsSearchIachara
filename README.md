# いあきゃら✦探索者検索

[いあきゃら](https://iachara.com/)のマイページに表示されるキャラクターデータを使って、探索者を検索・絞り込みできるChrome拡張機能です。

> ⚠️ いあきゃらの**非公式**ツールです。

## できること

- 名前・フリガナで検索
- SAN（正気度）・能力値で絞り込み
- 技能名と閾値で絞り込み（複数指定可）
- 6版 / 7版の切り替え
- ロスト探索者の表示 / 非表示
- ライト / ダークテーマの切り替え

## インストール方法

ストアには公開していないので、手動で読み込みます。ChromeとEdgeで使えます。

1. このページの [Releases](../../releases) から最新の `coc-ext.zip` をダウンロードして、解凍する
2. Chromeで `chrome://extensions` を開く（Edgeは `edge://extensions`）
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押して、解凍した `coc-ext` フォルダ（中に `manifest.json` があるフォルダ）を選ぶ

> **解凍したフォルダは、削除・移動しないでください。** 拡張機能が動かなくなります。

## 使い方

1. [いあきゃらのマイページ](https://iachara.com/mypage)を開く
2. ページの左下にアイコンが出る（データを読み込むまでは半透明）
3. アイコンを押すと、検索画面が新しいタブで開く

すでに検索画面のタブが開いている場合は、新しく開かずにそのタブが使われます。ツールバーの拡張機能アイコンからも、検索画面を開けます。

## 更新方法

1. 新しい `coc-ext.zip` をダウンロードして解凍する
2. 今のフォルダの中身を、新しいファイルで上書きする
3. `chrome://extensions` で、この拡張機能の更新ボタン（↻）を押す

自動更新はされません。

## 注意事項

- Chromeの起動時に、「デベロッパーモードの拡張機能を無効にしてください」といったポップアップが出ることがあります。ストア経由でない拡張機能すべてに出る、Chromeの標準の仕様です。閉じて、そのまま使えます。
- 取得したキャラクターデータは、ブラウザの一時的な保存領域にだけ置かれます。**ブラウザを閉じると消え、外部のサーバーには送信しません。**
- 検索画面の表示のため、Google Fontsからのフォント読み込みと、キャラクター画像のいあきゃら側からの読み込みで、通信が発生します。
- いあきゃら側の仕様が変わると、動かなくなることがあります。
- スマートフォンのブラウザでは使えません。
